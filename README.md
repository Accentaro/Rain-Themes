# Rain Themes

## Cove

One theme with two appearances: **Sunroom** in light mode and **Lantern Cove** in dark mode. Includes both original pixel-art wallpapers.

### Import into Rain

Paste this URL into Rain's theme installer:

https://raw.githubusercontent.com/Accentaro/Rain-Themes/main/theme.json

Select Light or Dark in the theme options to change appearance.

### Compatibility

Light/dark colors use Rain's spec 2 semantic color pairs. Switching wallpapers also requires a Rain build with support for `background.light` and `background.dark` (included in our development build). Clients without that support use the Lantern Cove wallpaper for both appearances.

The wallpapers are hosted in this repository; no local server is needed to download the theme or its assets.
